# Financial Controller

A financial management application with a Python (FastAPI) backend, a MongoDB database, and an HTML, CSS, and JavaScript frontend. It allows users to view, create, edit, and delete transactions, as well as track their balance.

The project is under development.

## Current Features

**Backend**

- List transactions.
- Create a new transaction.
- Edit an existing transaction (PUT).
- Delete a transaction (DELETE).
- Retrieve the balance.

**Frontend**

- Display the total balance, income (inflow), and expenses (outflow).
- Add transactions through a form with description, amount, type, and category fields.
- View transactions in a vertically scrollable list.
- Edit transactions through a responsive modal, centered on desktop and displayed as a bottom sheet on mobile, with opening and closing animations. The modal closes when clicking the X button, pressing ESC, or clicking outside it.
- Confirm transaction deletion through a modal, with a success toast displayed afterward.
- Render the transaction list using `textContent` to prevent HTML injection through transaction descriptions.

## Technologies

- Python
- FastAPI
- Uvicorn
- MongoDB (PyMongo)
- HTML, CSS, and JavaScript

## Data Storage

Transactions are stored in MongoDB and persist across application restarts. The connection is handled through PyMongo, and the data can be viewed using MongoDB Compass. Each transaction is identified by an `_id` generated by MongoDB.

## Prerequisites

- Python 3 installed.
- MongoDB Community Server running locally (at `mongodb://localhost:27017` by default).

## Running the Application

Run the commands below from the project's root directory. The virtual environment activation instructions are for Windows PowerShell.

### 1. Create a Virtual Environment

```powershell
python -m venv .venv
```

### 2. Activate the Virtual Environment

```powershell
.\.venv\Scripts\Activate.ps1
```

### 3. Install Dependencies

```powershell
python -m pip install -r requirements.txt
```

### 4. Start the Backend

With MongoDB running, execute:

```powershell
python -m uvicorn app.main:app --reload
```

This command runs the `app` application defined in `app/main.py`. The `--reload` option restarts the server whenever the code changes during development.

### 5. Open the Frontend

Serve the frontend HTML file using a local server, such as the Live Server extension for VS Code. The frontend communicates with the API at `http://localhost:8000`.

## API Endpoints

All endpoints use the `/financial` prefix.

| Method | Endpoint | Description |
| ------ | -------- | ----------- |
| GET | `/transactions` | List transactions |
| POST | `/transactions` | Create a transaction |
| PUT | `/transactions/{id}` | Update a transaction |
| DELETE | `/transactions/{id}` | Delete a transaction |

## API Documentation

With the server running, access the interactive documentation to explore and test the endpoints:

- Swagger UI: http://127.0.0.1:8000/docs
- ReDoc: http://127.0.0.1:8000/redoc

## CORS Configuration

CORS is restricted to a list of allowed origins (the production frontend and the local development server). Only the `GET`, `POST`, `PUT`, and `DELETE` methods and the `Content-Type` and `Authorization` headers are allowed.
